# 深度分析文章写作

## 提示词

```
你是一位经验丰富的商业分析师和内容创作者，擅长从复杂信息中提炼洞察。

请根据以下主题撰写一篇深度分析文章：

## 核心要求
1. **结构清晰**：使用清晰的标题层级和段落划分
2. **数据支撑**：引用具体数据和案例（如果有）
3. **洞察独到**：提供独特视角，避免陈词滥调
4. **实用性强**：给出可执行的建议或启发
5. **语言风格**：专业但不晦涩，有温度但不煽情

## 文章结构
- **标题**：吸引眼球但不夸张，准确概括核心观点
- **导语**：100-200字，快速切入主题，说明为什么现在读这篇文章
- **正文**：3-5个小标题，每个论点有数据/案例支撑
- **结语**：总结观点，给出展望或可执行建议

## 写作风格
- 避免使用"首先、其次、最后"等陈词滥调
- 使用具体例子和比喻来解释复杂概念
- 保持段落简短（3-5句话）
- 使用加粗强调关键观点

## 字数
1500-2500字

请根据我的具体主题和要求进行调整和优化。
```

## 使用场景

### 适用内容类型
- ✅ 行业趋势分析
- ✅ 技术深度解析
- ✅ 商业模式分析
- ✅ 产品评测
- ✅ 创业思考

### 不适用场景
- ❌ 新闻快讯（需要更简洁）
- ❌ 教程指南（需要更具体步骤）
- ❌ 轻松娱乐（需要更轻松风格）

## 使用技巧

### 1. 主题提供方式
**好的方式**：
```
主题：中国API中转站产业的崛起与生态重构
角度：从产业链上下游关系分析
预期读者：AI从业者、投资人
```

**不好的方式**：
```
写一篇关于API的文章
```

### 2. 约束条件
可以添加额外约束来调整输出：
```
请特别关注以下几点：
1. 创业机会在哪里
2. 潜在风险是什么
3. 给入局者的建议
```

### 3. 风格调整
```
风格参考：
- 专业度：80%（有数据支撑，但不晦涩）
- 可读性：70%（通俗易懂，但不肤浅）
- 实用性：90%（给出可执行建议）
```

## 优化建议

### 如果输出太泛泛
添加约束：
```
请避免：
- 宏观论述
- 陈词滥调
- 缺乏数据支撑的观点

请确保：
- 每个观点有具体案例
- 引用真实数据（如果有）
- 给出可执行建议
```

### 如果输出不够深入
添加要求：
```
深度要求：
- 不只是描述现象，要分析原因
- 不只是列举问题，要给出解决方案
- 不只是泛泛而谈，要具体到可执行步骤
```

### 如果风格不对
调整风格描述：
```
风格要求：
- 语气：客观、理性、有洞察
- 避免：过度乐观、夸大其词
- 使用：具体数据、真实案例
```

## 变体提示词

```

- 字数：800-1200字
- 结构：1个核心观点 + 3个支撑论点
- 风格：快速阅读，重点突出

```
请撰写一篇深度研究报告：
- 字数：3000-5000字

- 论证：3-4个有力论据
- 风格：有态度、有立场

## 常见问题

**Q: 提示词需要每次都完整输入吗？**
A: 建议创建模板，根据具体主题调整核心部分即可。

**Q: 如何确保输出符合自己的风格？**
A: 添加"风格参考"部分，提供你的文章样本或描述。

**Q: 输出质量不稳定怎么办？**
A: 检查输入是否清晰，考虑分步生成（先大纲，再填充）。

**Q: 能否生成特定领域的文章？**
A: 在提示词中添加领域背景和要求，效果会更好。
