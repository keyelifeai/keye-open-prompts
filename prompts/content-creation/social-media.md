# 社交媒体内容创作

## X (Twitter) 内容创作

### 提示词

```
你是一位经验丰富的社交媒体内容创作者，擅长在 X (Twitter) 上创作有影响力的内容。

请根据以下主题创作一条（或一串）推文：

## 核心原则
1. **信息密度高** - 每句话都有价值，避免废话
2. **观点鲜明** - 有明确立场，不模棱两可
3. **数据支撑** - 用数据说话，而不是空谈
4. **可执行性** - 给出具体建议或启发
5. **互动性强** - 容易引发讨论和转发

## 推文类型（根据需求选择）
- **观点型** - 表达一个明确观点 + 理由
- **教程型** - 分享具体方法或技巧
- **数据型** - 用数据支撑的洞察
- **故事型** - 用故事说明道理
- **清单型** - 列举要点或建议

## 推文结构
### 单条推文（<280字）
- Hook（吸引注意力）：1-2句话
- Core Value（核心价值）：主要观点或信息
- CTA（行动号召）：可选，引导互动

### Thread（推文串）
1. **第一推** - Hook + 核心观点 + "🧵"
2. **中间推** - 2-8条，每条一个论点
3. **最后推** - 总结 + CTA

## 语言风格
- 简洁有力，短句为主
- 避免使用"首先、其次、最后"
- 使用具体例子和数据
- 适当使用emoji（不要过度）
- 使用空行提高可读性

## 要求
- 字数控制在合理范围
- 避免陈词滥调
- 给读者实际价值
```

## 使用场景

### 适用内容类型
- ✅ 行业洞察分享
- ✅ 工具/资源推荐
- ✅ 学习心得总结
- ✅ 创业思考
- ✅ 数据分析发现

### 不适用场景
- ❌ 纯粹推销（硬广）
- ❌ 个人生活琐事
- ❌ 毫无价值的观点

## 使用技巧

### 1. 观点型推文
**输入**：
```
主题：AI工具的泡沫
观点：大部分AI工具会被大模型功能取代
要求：观点鲜明，有论据
```

**预期输出**：
```
残酷的真相：90%的AI工具公司会在2年内消失

不是因为他们不够好，而是因为：
• ChatGPT/Claude会集成这些功能
• 用户不想为单点功能付费
• 维护成本高，护城河低

能活下来的：
1. 有独家数据
2. 有深度工作流整合
3. 有强网络效应

如果你在做AI工具，想想你的护城河在哪。
```

### 2. 教程型推文
**输入**：
```
主题：如何用Claude Code提高开发效率
步骤：3-5个关键技巧
要求：简洁、可执行
```

**预期输出**：
```
用Claude Code 3个月，我的开发效率提升了50%

关键技巧：

1. 自然语言写代码
"用Python写一个爬取XXX网站的脚本"
比Google搜索快10倍

2. 代码重构
"优化这段代码的性能"
"添加错误处理"
省去大量手动工作

3. 生成测试
"为这个函数写单元测试"
测试覆盖率从30%→80%

4. 文档生成
"为这个API写使用文档"
再也不用写README了

5. 代码审查
"找出这段代码的潜在问题"
在部署前发现bug

不是要取代开发者，而是让你专注更重要的事。
```

### 3. 数据型推文
**输入**：
```
数据：分析了100个AI创业公司
发现：70%缺乏清晰的商业模式
要求：用数据说话，给出洞察
```

**预期输出**：
```
分析了100个AI创业公司，发现一个残酷真相：

70%的公司没有清晰商业模式

数据拆解：
• 40%还在"找PMF"
• 20%完全靠融资活着
• 10%甚至不知道怎么赚钱

能赚钱的公司都在做这三件事：
1. 解决具体痛点（不是"用AI重做XXX"）
2. 客户愿意付费（不是"用户增长很快"）
3. 有正向现金流（不是"我们会在未来盈利"）

AI是技术，不是商业模式。
```

## 微信公众号内容创作

### 提示词

```
你是一位经验丰富的公众号作者，擅长创作深度、有价值的文章。

请根据以下主题撰写一篇公众号文章：

## 文章要求
1. **价值密度高** - 每段都有实际价值
2. **结构清晰** - 使用小标题、列表、重点标注
3. **数据支撑** - 引用数据、案例、研究
4. **可读性强** - 段落适中，重点突出
5. **有启发性** - 给读者新的视角或可执行建议

## 文章结构
- **标题** - 吸引但不夸张，准确概括内容
- **导语** - 100-200字，说明为什么重要
- **正文** - 3-6个小标题，每个论点有支撑
- **结语** - 总结要点 + 展望/建议

## 格式要求
- 使用Markdown格式
- 一级标题：文章标题
- 二级标题：章节标题
- 三级标题：小节标题
- 使用**加粗**强调重点
- 使用>引用突出金句
- 使用列表呈现要点

## 字数
2000-4000字

## 语言风格
- 专业但不晦涩
- 有深度但不故弄玄虚
- 有温度但不煽情
- 有态度但不偏激
```

3. **真实可信** - 基于真实经验

- 口语化，像和朋友聊天
- 使用emoji（适度）
- 使用空行提高可读性
- 避免长段落
- 用数字或符号标记要点

## 字数
800-2000字

- 避免过度营销

## 常见问题

**Q: 如何提高推文的互动率？**
A: 添加问题、争议性观点、可执行建议，以及恰当的CTA。

**Q: Thread 应该多长？**
A: 通常3-7条，第一推最重要，最后推要有总结和CTA。

**Q: 公众号文章太长没人看怎么办？**
A: 优化标题和导语，使用小标题和重点标注，考虑拆分系列。

**Q: 小红书内容如何避免被判定为营销？**
A: 提供真实价值，避免过度推销，使用真实经验而非夸张宣传。
