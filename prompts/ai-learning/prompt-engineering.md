# 提示词工程 (Prompt Engineering)

## 提示词优化助手

### 提示词

```
你是一位提示词工程专家，精通AI模型（Claude、ChatGPT等）的交互技巧。

请分析以下提示词，并给出优化建议：

## 分析维度
1. **清晰度** (Clarity) - 指令是否明确、无歧义
2. **完整性** (Completeness) - 是否包含必要的要求和约束
3. **结构化** (Structure) - 是否有清晰的输出格式要求
4. **上下文** (Context) - 是否提供足够的背景信息
5. **示例** (Examples) - 是否需要添加示例来引导AI

## 输出格式
请按以下结构输出：

### 原提示词分析
- ✅ 优点：[列出做得好的地方]
- ⚠️ 不足：[列出需要改进的地方]

### 优化建议
1. **具体建议** - [改进点1]
2. **具体建议** - [改进点2]
3. **具体建议** - [改进点3]

### 优化后的提示词
```
[给出完整的优化版本]
```

### 改进说明
- [说明为什么这样改进]

### 使用技巧
- [给出使用这个提示词的建议]
```

- ✅ 优化现有提示词

## 实际案例

### 案例 1：内容创作提示词优化

**原提示词**：
```
写一篇关于AI的文章
```

**分析**：
- ❌ 主题太宽泛
- ❌ 没有风格要求
- ❌ 没有结构要求
- ❌ 没有长度要求
- ❌ 没有目标读者

**优化后**：
```
你是一位经验丰富的科技记者，擅长用通俗易懂的语言解释复杂技术。

请撰写一篇关于"大语言模型如何工作"的科普文章：

## 目标读者
- 对AI感兴趣的非技术读者
- 年龄：25-40岁
- 教育背景：本科及以上

## 文章要求
1. **通俗易懂** - 避免技术术语，必要时用比喻解释
2. **结构清晰** - 使用小标题，每个概念独立成段
3. **有启发性** - 不仅解释"是什么"，还要说明"为什么重要"
4. **避免过度炒作** - 客观陈述，不夸大其词

## 文章结构
- 标题：吸引但不夸张
- 导语：100-150字，说明为什么现在要了解这个
- 正文：3-5个小标题
- 结语：总结 + 展望

## 字数
1500-2000字

## 语言风格
- 专业但不晦涩
- 有温度但不煽情
- 使用具体例子和比喻
```

```

```

**分析**：
- ❌ 没有说明爬取目标
- ❌ 没有技术栈要求
- ❌ 没有异常处理要求
- ❌ 没有代码规范要求

**优化后**：
```

请编写一个Python网页爬虫：

4. **日志** - 添加logging，记录关键步骤
5. **延时** - 添加随机延时，避免被封

## 代码结构

    """获取网页内容"""
    pass

def parse_content(html):
    """解析网页内容"""
    pass

    """保存数据到文件"""
    pass

    """主函数"""
    pass

## 额外要求
- 添加配置项（如延时范围、重试次数）
- 添加类型提示（Type Hints）
- 添加使用示例

请给出完整代码 + 使用说明。

### 案例 3：数据分析提示词优化

**原提示词**：
```
分析这组数据
```

**分析**：
- ❌ 没有数据背景
- ❌ 没有分析目标
- ❌ 没有输出格式
- ❌ 没有分析深度要求

**优化后**：
```
你是一位数据分析师和商业顾问，擅长从数据中提取商业洞察。

请分析以下数据：

## 数据背景
[数据来源、时间范围、数据含义等]

## 分析目标
请回答以下问题：
1. 数据的整体趋势是什么？
2. 有哪些异常值或特殊模式？
3. 数据之间的相关性如何？
4. 有什么商业洞察或建议？

## 分析框架
1. **数据概览** - 基本统计信息
2. **趋势分析** - 长期趋势、季节性
3. **对比分析** - 同比、环比
4. **洞察提取** - 关键发现
5. **行动建议** - 可执行建议

## 输出格式
- 使用Markdown格式
- 关键数据用表格
- 重要发现用💡标注
- 风险警示用⚠️标注
- 建议按优先级排序

## 深度要求
- 不只是描述数据，要解释原因
- 不只是发现问题，要给出解决方案
- 不只是泛泛而谈，要具体到可执行步骤
```

## 提示词设计原则

### 1. 清晰明确 (Be Clear)
```
❌ 好的：写一篇文章
✅ 好的：撰写一篇1500字的科技文章，主题是"AI对内容创作的影响"
```

### 2. 提供上下文 (Provide Context)
```
❌ 差：分析这个代码
✅ 好：这是一段Python爬虫代码，用于爬取新闻网站文章。请分析其潜在问题：
- 性能问题
- 错误处理
- 可维护性
```

### 3. 明确输出格式 (Specify Output Format)
```
❌ 差：给我一些建议
✅ 好：请给出3-5个建议，每个建议包括：
- 建议：具体内容
- 理由：为什么这样做
- 优先级：高/中/低
```

### 4. 使用示例 (Use Examples)
```
❌ 差：按照我的风格写作
✅ 好：请按照以下风格写作：
"AI不是要取代人类，而是要让人类更强大。
就像计算器没有让数学家失业，而是让他们能解决更复杂的问题。"

风格特点：
- 简洁有力
- 使用比喻
- 有明确观点
```

### 5. 设置约束 (Set Constraints)
```
❌ 差：写一段代码
✅ 好：请用Python写一个函数，要求：
- 函数名：calculate_metrics
- 参数：data (List[Dict])
- 返回：Dict[str, float]
- 不使用pandas
- 添加类型提示和docstring
```

## 常见问题诊断

### 问题 1：AI 经常误解意图
**原因**：提示词不够清晰
**解决**：
- 添加具体的背景信息
- 明确说明要做什么
- 给出具体的例子

### 问题 2：输出格式不符合预期
**原因**：没有明确输出格式要求
**解决**：
- 明确说明输出格式（JSON/Markdown/表格等）
- 给出输出模板
- 说明每个字段的含义

### 问题 3：输出质量不稳定
**原因**：提示词缺乏约束或示例
**解决**：
- 添加"请避免"部分
- 提供"好的输出"示例
- 明确质量标准

### 问题 4：输出太泛泛
**原因**：缺乏深度要求
**解决**：
- 要求"不只是...还要..."
- 要求给出具体可执行建议
- 要求引用数据或案例

## 进阶技巧

### 1. 分步生成 (Step-by-Step)
```
请分步完成任务：

步骤1：先给出大纲
步骤2：确认大纲后，逐节填充
步骤3：最后整体优化

```

- 沟通风格：[说明]
```

```
请按照以下思路回答：
1. 先分析问题的本质
2. 然后考虑可能的方案
3. 最后给出最佳方案及理由
```

### 4. 迭代优化 (Iterative Refinement)
```
请先给出初步方案，然后根据以下标准优化：
- [标准1]

- [标准3]
```

## 常见问题

**Q: 提示词多长合适？**
A: 取决于任务复杂度。简单任务3-5行，复杂任务可以更长。关键是清晰，不是长度。

**Q: 如何判断提示词质量？**
A: 看输出是否稳定、准确、符合预期。如果不稳定，通常需要优化提示词。

**Q: 不同AI模型的提示词可以通用吗？**
A: 大部分可以，但每个模型有特点。建议针对具体模型微调。

**Q: 提示词需要每次都重新输入吗？**
A: 可以创建模板库，根据具体需求调整核心部分。
